# ecobiomass.gr

Ο ιστότοπος της **MSW Green Energy Greece IKE** για ανανεώσιμα στερεά καύσιμα βιομάζας, που παράγονται στο Κορωπί Αττικής.

🌐 **https://ecobiomass.gr**

## Προϊόντα

- **Μπρικέτα Easy-Break™**: μπρικέτα ελεγχόμενης διάσπασης, πακέτο 8 kg
- **Πυρόδισκοι™**: δοσομετρημένοι δίσκοι βιομάζας, πακέτο 6 kg
- **Easy-Break™ (Bulk)**: 32 kg, και παλέτες των 240 kg, 480 kg και 960 kg
